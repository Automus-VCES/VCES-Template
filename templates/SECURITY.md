## Reporting

Do not disclose vulnerabilities publicly before maintainers can assess them. Use GitHub private vulnerability reporting if enabled; otherwise use the verified private security contact configured by the project maintainers.

**Before publishing this policy:** Enable GitHub private vulnerability reporting or replace this instruction with a monitored private contact/channel. Do not leave this template as the project's final reporting instructions while no private channel is configured.

Include affected version/component, impact and attack conditions, safe reproduction details, and mitigation if known. Do not include credentials, real user data, or sensitive production information.
