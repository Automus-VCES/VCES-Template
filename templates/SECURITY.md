## Reporting
Do not disclose vulnerabilities publicly before maintainers can assess them. Use GitHub private vulnerability reporting if enabled; otherwise contact [security contact / private maintainer channel].

Include affected version/component, impact and attack conditions, safe reproduction details, and mitigation if known. Do not include credentials, real user data, or sensitive production information.
