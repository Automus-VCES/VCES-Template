# Vibe Coding Engineering Standard (VCES)

A reusable, technology-agnostic engineering standard and repository template for AI-assisted and human-led software development.

This repository is the canonical source for VCES. Project repositories should adopt the standard and customize project-specific requirements without copying or contradicting universal rules.

See `VIBE-CODING-STANDARD.md` for the standard, `docs/ADOPTION-GUIDE.md` for rollout instructions, and `templates/` for project-ready documents.

**Current release:** 1.0.0 (initial template baseline)
